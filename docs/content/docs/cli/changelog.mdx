## 0.7.0 - 2026-08-30

The 0.7.0 release adds optional financial-effects and settlement reconciliation. Configure
`parser.financials` to evaluate fixed, percentage, fixed-plus-percentage, or component-sum
expectations in minor units. Results expose financial-effect and settlement events across all
reconciliation output formats, and financial differences participate in `exceptions_only` and
`--fail-if-exceptions`.

## Implemented docs surface

The docs site treats the following as implemented because the current CLI code contains them:

- `reconify config init`
- `reconify config validate`
- `reconify config check-source`
- `reconify capabilities`
- `reconify schema capabilities`
- `reconify parse`
- `reconify reconcile`
- Parser support for CSV, JSON, NDJSON, XLSX, and XLSM.
- Output formats `json`, `json-stream`, `ndjson`, `csv`, and `table`.
- Audit output through `--audit`.
- Deterministic JSON ordering through `--deterministic`.
- Progress logging through `--progress`.
- Memory, disk, and auto right-side index backends.
- Published Engine capabilities schema `reconify.engine.capabilities.v1`.
- Optional financial-effects and settlement checks through `parser.financials`.
- Financial and settlement result events in JSON, JSON-stream, NDJSON, CSV, and table output.
- Financial summary counters, explanations, published result schemas, and CI exit-policy support.

## Planned or not yet documented as implemented

Some changelog entries describe behavior that is not present in the inspected CLI implementation. These are kept in [Upcoming](/docs/cli/upcoming) until implemented:

- default validation before reconciliation
